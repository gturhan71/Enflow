## 6. Bulgular

### BUG-01 · KRİTİK · Tenant İzolasyonu Eksik (IDOR)
- **Ciddiyet:** Kritik
- **Etkilenen roller:** Tüm (cross-tenant saldırı)
- **Tip:** Tenant izolasyonu / IDOR
- **Adımlar:**
  1. Tenant-2 kullanıcısı (`ali.mal@enflow.com`) login ol, kendi token'ını al
  2. API isteğinde `x-tenant-id: tenant-1` header'ını gönder
  3. `GET /api/customers` çağır
- **Beklenen:** 403 Forbidden
- **Gerçekleşen:** 200 OK + tenant-1'in tüm müşteri listesi (ör. ADALET BAKANLIĞI verisi)
- **Kök neden:** `tenantMiddleware` yalnızca tenant'ın DB'de var olup olmadığını kontrol ediyor. Kullanıcı ile tenant eşleşmesi doğrulanmıyor.
- **Öneri:** Middleware'e kullanıcı kimliği doğrulaması ekle — her istekte token'dan/header'dan userId çek, o kullanıcının `tenantId` alanını kontrol et.

---

### BUG-02 · Yüksek · RBAC Enforcement Eksik (18 endpoint)
- **Ciddiyet:** Yüksek
- **Etkilenen roller:** PRESALES_ENG (9 endpoint), SALES_REP (9 endpoint)
- **Tip:** API yetki / RBAC
- **Adımlar:**
  1. PRESALES_ENG token'ıyla login ol
  2. `GET /api/users` veya `POST /api/units` gibi kısıtlı endpoint'e istek gönder
- **Beklenen:** 403 Forbidden
- **Gerçekleşen:** 200 OK (tam erişim)
- **Kök neden:** Backend route'larında hiçbir rol koruması (role guard) yok. `tenantMiddleware` yalnızca tenant varlığını kontrol ediyor; kullanıcı rolüne göre filtreleme yapılmıyor.
- **Öneri:** `requireRole(['GENERAL_MANAGER'])` şeklinde middleware factory oluştur, kritik route'lara uygula.

---

### BUG-03 · Düşük · UI Sidebar Selector Uyumsuzluğu
- **Ciddiyet:** Düşük (test script sorunu — gerçek güvenlik açığı değil)
- **Tip:** Test doğruluğu
- **Adımlar:**
  1. `ui-access.spec.ts` içindeki sidebar metni kontrolü başarısız
  2. "Ön Satış" ve "CRM" metinleri sidebar'da farklı yazılmış veya henüz yüklenmemiş olabilir
- **Öneri:** Sidebar'daki gerçek label metinlerini kontrol et, test selector'larını güncelle. Bekleme süresini artır ya da `waitForSelector` kullan.

---

### BUG-04 · Düşük · Oturumsuz Login Testi Başarısız
- **Ciddiyet:** Düşük (test script sorunu)
- **Tip:** Test doğruluğu
- **Adımlar:**
  1. Temiz browser context ile uygulamaya git
  2. Login butonu aramak için `/giriş yap/i` regex kullanılıyor
  3. Eleman bulunamıyor
- **Olası neden:** Playwright'ın yeni context'i localStorage sıfırlamasına rağmen sayfa SPA olarak yükleniyor; "Giriş Yap" butonu bekleme süresi içinde render edilmiyor.
- **Öneri:** `page.waitForSelector('input[type="email"]', { timeout: 5000 })` ile daha güvenilir bekleme ekle.
