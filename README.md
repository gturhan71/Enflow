# Enflow — Kurumsal Süreç İşletim Sistemi

Enflow, modern bir işletmenin satış öncesi (presales), satış (CRM), maliyetlendirme, sözleşme yönetimi, satın alma ve proje uygulama süreçlerini tek bir çatı altında toplayan **End-to-End Enterprise Process Management (ERP & CRM)** platformudur.

## Sürüm v1.6.0
- **Durum:** Production-Ready
- **Özellikler:** 
  - Ticari (Proprietary) Lisanslama Modeli
  - Hibrit AI Abonelik Entegrasyonu
  - Master License Key & Trial Sistemleri
  - Enflow Mobile (Pocket ERP) - PWA & Responsive UI
  - Granular Workflow & Hand-off Bildirim (WhatsApp/Exchange) Otomasyonu

## Mimari
- Frontend: React 19 + Tailwind CSS + Framer Motion
- Backend: Node.js (Express) + Prisma 7 + LibSQL
- Güvenlik: RBAC (Permission Gate), Multi-tenant Veri İzolasyonu

Daha fazla detay için `walkthrough.md` dosyasını inceleyin.
